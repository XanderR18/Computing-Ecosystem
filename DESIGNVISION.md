# Design Vision for my Computing Ecosystem
The overall goal is to have my own standalone development/computing environment that allows me to essentially do ANYTHING I want, no limitations, just pure capability. From simple coding projects, to hardware tools, to agentic AI, if I have the idea, this should permit me to bring it to life. My home base for all operations that contains everything I need. It is modular and can easily be upgraded, expanded and replaced. Vibes wise, I want it to reflect my interest in Cyberpunk 2077 and be my catalyst for merging technology and life and immerse me in the world of technological possibility while also learning applicable concepts.
## What capabilities should my infrastructure provide over the next 2–3 years?
### Remote Access
- RDP for off ste devices
- VPN for incoming and outbound traffic
- SSH (?)
### Development
- Workspace to code and develop individual projects start to finish and beyond
- Continous implementation and continous deployment (CI/CD) for projects
### Network Intelligence
- Build, test, and host network tools (eg. network terminal tool)
- Learn, practice and apply networking skills and concepts
- Learn ethical hacking tools and skills
### Learning Platform
- Networking learning environment
- Automation learning environment
- AI learning environment
### Storage & Backups
- Have a place where I can store whatever I need in an organized fashion, potentially elimination subscriptions or other services
- Have a self sustaining environment. If things go south or offline, I can still access, connect, and work with things like the internet
- Have my own data center or digital storage unit
### Field Operations
- Have the tools to build and create hardware tools like cyberdecks, ESP32 & Raspberry Pi type tools, aloong with other fun hardware projects
- Do practical pprojects that can be applied in the real world with other networks, devices, etc.
- Create tools like a Cyberpunk 2077 netrunner
### Artificial Intelligence
- Learn and build my own AI tools
- Create offline/standalone AI devices and implementations
- Practice agentic stuff
## Conclusion
This project will serve as my home base to learn new things, work on my current projects, and bring to life my technological dreams and visions. I have a lot of stuff I want to do so I value the project being easily expandable so I can start new things whenever. This will be my Cyberpunk 2077 netrunner home base.
